## What already exists (read the code, don't rebuild it)
- **South-pole heat map (works today):**
  - Data: `engine/make_heatmap.py` → `data/heatmap/` (8-bit grayscale PNGs + `index.json`). Layers: `sunlit`, `earth`, `both` (value = round(pct × 2.55)), `dark` (longest blackout in days, 255 = 255+). Whole period + 24-month atlases.

## M15 · Whole-Moon heat map (~2–3 h)
Goal: the MAP layers (Sunlight / Earth contact / Both / Longest blackout, with Period) cover the **entire Moon** on the globe, with the existing high-detail south-pole map still drawn on top near the pole.

### 1. Engine: global layers (Python)
- New script `engine/make_heatmap_global.py` (copy the structure of `make_heatmap.py`, reuse its ephemeris loading and rules).
- For every point of `global_coarse` (360 × 181 = 65,160 points) and every hour (17,544):
  - Site vector on a sphere R = 1737.4 km (+ the grid's `observer_height_m`), local east-north-up frame, Sun/Earth azimuth + elevation **from the site** (subtract the site vector: Earth parallax matters), exactly as `core/fhls-core.js` does.
  - Horizon at that azimuth: linear interpolation between the 72 bins.
  - sunlit / earth / both / longest dark, same encoding as the south-pole layers.
- Vectorise with numpy and use all cores (`multiprocessing.Pool`, chunk by latitude rows). Target: under ~15 min on a laptop. If too slow, process every hour but in float32, or start with the whole-period layers and do monthly only if time allows.
- Output to `data/heatmap/`: `global_<layer>.png` (360 × 181, 8-bit grayscale, **row 0 = latitude +90 (north), column 0 = longitude −180**), optional `global_<layer>_months.png` atlas (same layout rule as the south-pole atlas). Add a `"global"` entry to `data/heatmap/index.json` with projection `equirectangular`, lat/lon extents, size, `precision: "low"`.
- Sanity checks before pushing (print them, put the numbers in LOG.md):
  - Near the equator on the near side: sunlit ≈ 50 %, earth ≈ 100 %.
  - Far side (e.g. 0°N, 180°E): earth ≈ 0 %.
  - Results near −85° should be in the same ballpark as the south-pole high-res layers (they won't match exactly: coarse vs fine terrain).
- **Engine/data files belong to T3.** Say in LOG.md "@T3 adding engine/make_heatmap_global.py and data/heatmap/global_* for M15"; don't modify `make_heatmap.py` or the existing south-pole files.
